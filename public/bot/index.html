BBTSL bot notes

The bot uses the live item list. Favorites are stored by Discord user ID and card ID, so website and bot changes land in the same place.

Commands

Slash replies are public unless they show private user data. The bbtsl- text commands are there when slash commands are slow, missing, or not available in that channel.

SlashTextNotes
/item item:#ADFJCFbbtsl-item #ADFJCFOpens one card.
/search query:frogbbtsl-search frogSearches names, IDs, categories, demand, and trend.
/top metric:valuebbtsl-top valueRanks by value, demand, count, or trend.
/updatedbbtsl-updatedShows recent item changes.
/compare first:#AAA111 second:#BBB222bbtsl-compare #AAA111 #BBB222Compares two cards.
/teambbtsl-teamShows the public team list.
/statusbbtsl-statusChecks whether the bot can reach BBTSL.
/favorite listbbtsl-favorite listPrivate reply. Shows your saved cards.
/favorite add item:#ADFJCFbbtsl-favorite add #ADFJCFPrivate reply. Saves a card.
/favorite remove item:#ADFJCFbbtsl-favorite remove #ADFJCFPrivate reply. Removes a card.

Staff

Staff commands use the role on the team page. Run /help from the account that has access.

  • Use card IDs when editing. Names can collide or change.
  • Use audit commands for records and revert IDs, not as a replacement for item search.
  • Keep exports out of public channels unless the owner approved the share.
  • Do not use team-user commands to test public command behavior.

Item IDs

Every card has a six-character ID. Use the ID when you want Discord to open the same item the website shows.

  • /item item:#ADFJCF
  • /search query:frost
  • /favorite add item:#ADFJCF
  • bbtsl-item #ADFJCF
